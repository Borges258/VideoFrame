# VideoFrame 使用手册

**VideoFrame** 是一个纯网页的 **视频帧处理 + 图片转换** 小工具。

所有处理（视频解码、像素编辑、格式转换、压缩打包）都在你自己的浏览器里完成，**文件不会被上传到任何服务器**，也无需安装任何东西。

它包含两个功能页面：

| 页面 | 用途 |
| --- | --- |
| `index.html` | 把 MP4 视频切成 PNG 帧，编辑后导出为 ZIP 或 GIF |
| `convert.html` | 图片格式互转（JPG / PNG / WebP / ICO / RAW），转换前还能修图 |

页面右上角可以随时在这两个功能之间切换。

## 快速开始

### 方式一：在线使用（推荐）

直接打开上面的 GitHub Pages 网址。

### 方式二：本地使用

1. 下载并解压本项目到任意文件夹。
2. 直接**双击** `index.html` 或 `convert.html`，用浏览器打开即可。
3. 建议使用 **Chrome / Edge**（近几年的版本都可以）。

> 也可以在本项目文件夹里执行 `python -m http.server 8000`，
> 然后访问 `http://localhost:8000/index.html`。

## 功能一：视频帧处理

### 第 1 步：上传视频并提取帧

1. 把 **MP4** 文件拖到虚线框里，或点「点击选择文件」。
2. 加载成功后，设置提取参数：

| 参数 | 说明 | 建议 |
| --- | --- | --- |
| **每秒帧数 (FPS)** | 每秒抽多少帧。数值越大越流畅，帧数也越多 | 做 GIF 用 8~12 即可 |
| **最长边像素** | 输出画面的最大边长，等比缩放 | 720 或 480 足够 |
| **最大帧数** | 帧数上限，超出会按时间均匀抽取 | 200 以内较流畅 |

3. 点「🎬 提取帧」，等待进度条走完。

> 页面会实时显示「预计提取 N 帧」，方便你提前调整 FPS。

### 第 2 步：编辑帧

提取完成后，底部会出现**帧序列缩略图**。点击任意一张即可开始编辑。

| 工具 | 作用 | 快捷键 |
| --- | --- | --- |
| 🖌️ **画笔** | 添加像素（用选定颜色涂画） | `B` |
| 🧽 **橡皮** | 删除像素（变为透明） | `E` |
| 💧 **取色器** | 从画面上吸取颜色 | `I` |
| ↶ ↷ **撤销 / 重做** | 回退或恢复操作 | `Ctrl+Z` / `Ctrl+Y` |
| ⟲ **重置本帧** | 恢复成刚提取出来的样子 | — |
| − 适应 ＋ | 缩放画面；放大到 800% 以上会显示像素网格 | — |

**画布尺寸调整**（右侧面板）：

- 输入新的宽 / 高，选择「对齐」方式，点「应用尺寸」。
- 缩小会裁掉超出部分；放大则以透明区域填充。
- 对齐方式决定原有画面贴在新画布的哪个位置（居中、左上、右下等）。

**帧操作**：

- 「⧉ 复制当前帧」复制一张一样的帧（做停顿效果很有用）。
- 「🗑 删除当前帧」删掉这张帧。
- 用键盘 **← / →** 可以快速切换上一帧 / 下一帧。

所有修改都会**自动保存**到对应的 PNG 帧上，不需要手动保存。

### 第 3 步：导出

导出方式二选一：

**① 导出 ZIP（全部 PNG）**

- 把所有帧打包成一个 `.zip` 文件下载。
- 保留透明通道和每张帧的原始尺寸，适合继续在别的软件里处理。

**② 导出 GIF（动画）**

| 参数 | 说明 |
| --- | --- |
| **帧延迟 (ms)** | 每帧停留多少毫秒。默认会按提取时的 FPS 自动填好 |
| **循环** | 「无限循环」或「播放一次」 |
| **背景** | 「透明」，或填成白色 / 黑色 |

点「下载 GIF」即可得到动画文件。

> 小技巧：GIF 体积和帧数、尺寸正相关。想要小体积，就把「最长边像素」设小一点、FPS 设低一点。

## 功能二：图片转换与编辑

`convert.html` 可以批量转换图片格式，并在转换前对图片做修改。

### 添加图片

- 把图片拖入虚线框，或点「点击选择文件」（**支持一次选多张**）。
- 支持的输入：**JPG / JPEG / PNG / WebP / GIF / BMP / RAW**。
- 添加后，下方会列出所有图片的缩略图。

### 编辑图片（转换前修图）

把鼠标移到缩略图上，点右上角的 **✎** 按钮，即可打开编辑面板：

| 工具 | 作用 |
| --- | --- |
| 🖌️ **画笔** | 用选定颜色涂抹（可调笔刷大小 1~32 px） |
| 🧽 **橡皮** | 擦除为透明 |
| 💧 **取色器** | 吸取画面上的颜色 |
| ✂️ **裁剪** | 在画布上**拖拽框选**区域，再点「应用裁剪」 |
| ↶ ↷ ⟲ | 撤销 / 重做 / 重置 |
| 缩放 | 放大后会出现像素网格，方便精细修改 |

右侧还有两个面板：

**🖼️ 画幅比例** — 快速把图片改成标准比例：

- 比例：`1:1`、`4:3`、`3:4`、`3:2`、`2:3`、`16:9`、`9:16`
- 方式：
  - **适应** = 完整保留画面，不足的地方留透明（不裁切）
  - **填充** = 铺满目标比例，多出来的部分裁掉
- 「应用到当前图」只改这一张；「**应用到全部图片**」把相同设置套用到所有图片（做统一尺寸的头像、图标时很方便）。

**📐 画布尺寸** — 直接指定宽高，并选择对齐方式。

改完后点右上角「**保存修改**」，缩略图上会出现「已编辑」标记；点「取消」则丢弃本次修改。

> 编辑只影响转换输出，**不会改动你磁盘上的原始文件**。

### 输出格式

| 输出格式 | 说明 |
| --- | --- |
| **JPEG (.jpg)** | 有损压缩，体积小，不支持透明。透明区域会用所选背景色（白 / 黑）填充，可调质量 |
| **PNG** | 无损，支持透明，体积较大 |
| **WebP** | 体积小、支持透明，可调质量，现代浏览器与系统都支持 |
| **ICO 图标 (.ico)** | Windows 图标格式，**可多选尺寸**生成多分辨率图标 |
| **RAW（原始像素）** | 无文件头、无压缩的原始像素数据，可指定通道布局 |

#### ICO 图标输出

选择「ICO 图标」后，会多出一行**尺寸多选框**（16 / 24 / 32 / 48 / 64 / 128 / 256）：

- 勾选**一个**尺寸 → 生成单尺寸图标。
- 勾选**多个**尺寸 → 生成**多分辨率图标**（一个 .ico 里包含多个尺寸，系统会自动挑最合适的显示）。
- 图片会等比缩放到正方形画布内（完整保留，多余部分透明填充）。
- 建议先在上面的编辑器里把「画幅比例」设成 **1:1**，图标会更规整。

> 图标单边最大 256 像素，这是 ICO 格式本身的限制。

#### RAW 格式说明

RAW 指的是**未压缩的原始像素数据**（不是相机厂家的 CR2/NEF 这类专有格式，浏览器无法解析那些）。

- **导出 RAW**：选择「通道布局」，导出 `.raw` 文件。
- **导入 RAW**：把 `.raw` / `.bin` 文件拖进来，然后**填写宽度、高度和通道布局**，才能正确显示和转换。

可选布局：`RGBA`、`BGRA`、`RGB`、`BGR`、`灰度 GRAY`。

### 转换并下载

设置好输出格式与参数后，点「⬇ 转换并下载」：

- 只有 **1 张**图片 → 直接下载转换后的文件。
- 有 **多张**图片 → 自动打包成一个 `converted_images.zip` 下载。

右上角的下拉框可以切换界面主题：

## 常见问题

**Q：视频为什么加载失败 / 没有画面？**
A：浏览器只能解码它自己支持的编码（通常是 H.264 的 MP4）。如果视频是特殊编码（如 HEVC/H.265、AV1 的某些封装），可能无法解码。可先用其他工具转成标准 H.264 MP4。

**Q：提取出来的帧很多，页面卡顿怎么办？**
A：降低「每秒帧数 (FPS)」和「最长边像素」，或调小「最大帧数」。帧数越少越流畅。

**Q：编辑后想改回去？**
A：用「⟲ 重置」（恢复本帧原始画面）或 `Ctrl+Z` 撤销。图片转换页可以点「取消」放弃未保存的修改。

**Q：GIF 颜色有点花 / 有色带？**
A：GIF 格式最多只能有 256 种颜色，渐变画面会有轻微色阶。换成 PNG 或 WebP 输出可以避免。

**Q：导出的 ZIP 里是什么？**
A：就是每一帧的 PNG 图片，按 `frame_0001.png`、`frame_0002.png`… 顺序命名。

**Q：ICO 图标在系统里显示不正确？**
A：请确认勾选了合适的尺寸（桌面图标常用 32 / 48 / 256）。Windows 会从多分辨率图标里自动挑选。

**Q：支持透明背景吗？**
A：PNG、WebP、GIF、ICO 都支持透明；JPEG 不支持透明，会用你选择的背景色填充。

**Q：我的文件会被上传吗？**
A：不会。所有处理都在浏览器本地完成，断网也能用。

## 注意事项

- 建议使用 **Chrome / Edge** 等现代浏览器的最新版本。
- 视频解码能力取决于浏览器本身；个别编码的 MP4 可能无法打开。
- 处理超大视频或超多帧会占用较多内存，建议先用较小的「最长边像素」和 FPS 试跑。
- 所有操作都是**本地临时**的，刷新页面后当前编辑内容会丢失，请及时导出。
